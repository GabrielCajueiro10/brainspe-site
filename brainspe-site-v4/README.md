# Brainspe Site V5 — versão multipágina

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Páginas incluídas

- `/`
- `/inspecao-nr13`
- `/vasos-de-pressao`
- `/caldeiras`
- `/compressores`
- `/calibracao`
- `/prontuario-nr13`
- `/livro-de-registro`
- `/conhecimento`
- `/contato`

A Home permanece objetiva. O conteúdo detalhado está separado nas páginas próprias, acessíveis pelo menu.
